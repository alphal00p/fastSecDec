The small test-only adapter delegates to the existing production subtraction
owner. It reconstructs only the retained native mapped-term fields and does not
implement differentiation, boundary algebra, or a second IBP algorithm. The
preparation probe first requires exact equality between a fresh default Taylor
subtraction and the original captured expression, including the 872-piece

capture is bound to representative 80, source chart 119, multiplicity four,
nine coordinates, and the original 2,112-chart/1,026-representative input.
Neither expression is multiplied by the representative multiplicity.

Taylor and IBP are integral-equivalent through the native boundary identities;
their resulting pointwise densities generally differ. The proposed oracle
therefore reads the exact newly exported IBP expression, substitutes each
prescribed rational point using native literal variable replacement, and only
then asks native Series for its Laurent expansion. It retains the native
absolute remainder, retries relative widths with checked integer arithmetic,
rejects fractional powers and vacuous requested vectors, and fills only native
zero gaps inside the proven range. Every retained coefficient must agree at
512 and 1,024 bits. No Taylor coefficient is used as a pointwise IBP target.

The later program test remains gated on three complete, source-bound oracle
records that contain the exact preparation record and IBP expression digest.
It runs the real production Laurent and native program builders, compares over
the union of both inferred order sets through the finite coefficient, and keeps
zero orders explicit. It separately exercises fresh and same-process decoded
production kernels at identical rounded binary64 coordinates, with weights one
and 1e40, ordinary evaluation and forced replay. Those checks are not described
as a fresh-process artifact or full-integral test.
