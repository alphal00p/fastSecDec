# Runtime stability stack implementation evidence

Date: 2026-10-07. This is author evidence; the independent kernel/codec review is recorded separately.

The new default is the requested distance heuristic, using existing cancellation rows without altering their uniform-threshold semantics. The native evaluator runs at f64, 106-bit `DoubleFloat`, or `Float` with 1000 decimal digits. Numerica's `Float::decimal_digits_to_bits(1000.0)` returns 3322 bits; no new numeric type, symbolic evaluator, or dependency patch is introduced. Exact evaluator IR is mapped through the existing Symbolica callback-aware mapping adapter. Real and complex values are weighted at the selected precision before conversion to the external f64 result vector.

Exact original powers are carried by the generation owner through subtraction, IBP and named coefficient generation. Version 7 native binary metadata retains those typed profiles and validates their projection against the existing cancellation rows. Each per-power normalized logarithmic budget uses the precise original rational power, not the Taylor degree as a proxy. Multiple source alternatives on a conservatively mapped axis use their maximum budget. Uniform defaults continue to use the previous cancellation rows directly. Versions 5 and 6 retain original bytes and identities; old ambiguous or missing provenance rejects per-power overrides and requests regeneration rather than guessing.

The whole Laurent vector advances together when any complex coefficient exceeds the configured fraction of its previous nonzero weighted maximum. The first observation and zero reference maxima skip that check. Caller-supplied accepted baselines remain immutable across workers, while final finite local values update that worker's reference in sample order. Only complete admitted work merges persistent replay state. Runtime policy belongs to replay/checkpoint identity and does not change the physical kernel or parameter-point identity. Legacy replay state without the new policy field explicitly means the old validated policy.

A configured unstable-distance cutoff returns an explicitly classified zero without an evaluator call and without updating weighted maxima. It is disabled by default and may bias an integral when enabled. Nonfinite values advance through the numerical stack, and persistent failures remain errors. The distance heuristic deliberately does not invoke the old component-zero/subnormal test or successive-precision agreement: that test promoted every weighted purely imaginary ggHH value. This choice follows the approved heuristic policy, not a proof that small distances or finite outputs certify accuracy. Finite underflow and cancellation beyond the fixed final precision can remain undetected. The old conditioning/agreement policy remains explicitly selectable.

Final point classes and attempted evaluator calls are separate. Each native evaluator call has its own elapsed duration, including calls later superseded by a higher precision. Conditioning calls count toward total evaluator work but not the primary-f64 average. A failed call remains in the context's cumulative metrics so caller diagnostics can account for it even when evaluation returns an error. Historical diagnostic records lacking class fields expose their unclassified count instead of inventing a historical histogram.

Focused ignored public/native probes passed real and complex DoubleFloat mapping, an analytic complex Laurent-vector example with runtime parameters, all three distance classes, weights applied exactly once, version-7 cold values, exact power overrides, explicit cutoff zeros, all three attempted-call counters during weighted escalation, cross-point and cross-policy replay rejection, and unchanged version-5/version-6 artifact bytes. Sources and logs are under `output/runtime-dashboard/`; `stability-stack-probe.txt` contains the main execution result. Root separately validated four endpoint-profile routes (both coefficient methods with Taylor and IBP) and the portable build. The permanent tests/gates migration remains explicitly deferred.

Additional ignored acceptance controls passed both default threshold equalities and adjacent values on either side, rejection of an escalation fraction on the final numerical level, a genuinely divergent `x^(-1/2)` endpoint remaining an error with cutoffs disabled, and a very large finite weighted result remaining numerical at the final level. The first endpoint control used an analytically removable endpoint and was corrected to this genuinely divergent fixture; no production change was needed.

A two-axis generated example retained the native canonical coordinate permutation and original powers 1 and 2. An independently calculated logarithmic risk from those public typed profiles agreed with all three classes when only power 2 had an override and power 1 inherited the global thresholds. A QMC control compared callback points and weights against the native Korobov-3 transform applied to the corresponding untransformed lattice points: routing followed the transformed coordinates, with 19 of 256 points selecting a different class from the raw coordinate. The Jacobian was supplied once.

Root independently ran the portable eager host build through fresh generation, version-7 serialization, runtime binding, DoubleFloat/3322-bit evaluation, weighted escalation and cutoff handling, followed by a complete 4096-point QMC calculation with the analytic complex coefficients `[0, 1, 0, -ln(3)]` and full covariance. The log is `output/runtime-dashboard/portable-stack-probe.log`. This demonstrates the portable backend on this host; it does not claim a browser/Wasm or Pyodide execution. Native DoubleFloat callback conversion also reuses the owner's `EvaluationDomain` implementation in `src/evaluate/domain.rs:186,222`, whose documented fallback resolves the native `Float` callback if a dedicated DoubleFloat callback is absent.

The final release-linked probe also passed the independent review's public merge control: after observing weighted maxima 100 and 50 in separate contexts, merging the latter into the former retains a reference of 100, and a subsequent 60 stays at f64 under a 0.9 fraction. All earlier controls were rerun against the same final release library. Log: `output/runtime-dashboard/stability-stack-probe-release.txt`.
