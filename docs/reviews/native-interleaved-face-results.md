# Test-only native interleaved-face resolver

The preceding passive trace attributes the captured representative's timeout
to lowering whole native mixed partials before their faces. The reviewed
mathematical restriction is recorded in `native-interleaved-face-proposal.md`.
This experiment changes only test-owned named regular-coefficient resolution;
the original mode remains the default and production generation is unchanged.

The selectable candidate accepts only own-coordinate, exact-zero and exact-one
arguments, with at least one constant face. It applies zero-depth faces first,
then each axis's native derivatives followed by that axis's own face. The
regularity at the selected face is inherited from the admitted regular-body
scope; the resolver does not compute limits or extend singular-domain admission.
Composed arguments, swaps, other numbers and face-free requests use the original
whole-partial/simultaneous-substitution route. Face-dependent values enter only
the full-request cache, never the unsubstituted derivative cache. Counters
identify which route ran without making accuracy or performance claims.

The first core snapshot compiled in 17.28 seconds and is frozen under
`output/diagnostics/native-interleaved-faces-small-1`, with 16 hashed files and
copied native source archives. The development/test binary retains native
opt-level two and the existing feature set. Its ten normal controls include two
new native exact checks for mixed polynomial/rational/log derivatives, zero/one
faces, later-axis zero-depth faces, exact zeros, fallback argument shapes and
cache reuse. Existing complete-vector/error tests compare both modes against
the unchanged native subtraction/series path under Taylor and IBP, including
finite and negative requested orders. Two prior actual replay tests stay ignored.

The bounded core process is separate from the forthcoming native program,
512/1024-bit, weighted replay, worker clone and fresh-process IR controls.
Neither layer alone certifies the actual captured representative or a whole
graph. All original-expression oracle and full-order checks remain required.

The first bounded core gate passed all ten normal controls, with two prior
replays ignored, exit zero and no timeout. It completed in 0.192101553 seconds
with 15,360 KiB peak child RSS. All 16 source/build hashes passed postflight.
Both resolver branches and exact zero/nonzero controls executed; the original
mode remains the default. These are correctness diagnostics, not performance
acceptance. The reviewed program extension uses a distinct ignored candidate
writer and records the resolution mode in both writer and cold-reader records.
