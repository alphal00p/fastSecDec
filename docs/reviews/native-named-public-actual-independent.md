The helper calls public `generate`, `compile` and `KernelSet::to_bytes`.

its target order against the generated evaluator parameters, and derives the
point translation from that chart. It requires dense complete signed orders
through zero, matching output/component lengths and native literal-zero exact
offsets. Nonzero exact contributions cannot be silently omitted by this fixed
gate. Fresh conservative conditioning must match the mapped endpoint bound.

Separate reader processes first call public `KernelSet::from_bytes` before
diagnostically decoding the validated artifact's native evaluator bytes with
the existing native codec. Their reviewed contract compares the full signed
order union against all three accepted original-expression oracles at exact
rational coordinates, then checks rounded coordinates, public weighted worker
contexts and forced higher-precision replay. This is pointwise evidence;
there is no new QMC estimate or covariance in this gate.
