# Quotient normalization, relative SNC and a first monomial center

The native `threshold::resolution::geometry` modules add three constructive
operations to the reviewed local resolution primitives. They are not a general
BM resolution producer and construct no real atlas, blowup map or
exceptional-history transition yet.

## Native operations and proofs

`QuotientNormalizer` caches the native basis of the unchanged relation ideal K,
including every inverse-guard equation. It forms a native basis of I+K and
reduces its generators modulo K. Before publishing the result it proves both
ideal inclusions in this same localization. Mark, ordered coordinate roles and
parameter symbols are unchanged. All coefficients remain in Q, with parameters
retained as variables; in particular p*x is not normalized to x. The cache is
bound to an immutable local owner. A candidate generated in another ring, with
another mark or a missing generator is refused. Exact zero and unit quotient
ideals are valid outcomes, not a global real-fiber resolution claim.

The implementation reuses Symbolica's `GroebnerBasis::new`, native polynomial
`reduce`, and the existing native ideal/guard operations. Public API, source and
executable evidence are recorded in
`target/no-deformation-quotient-normalization-probe/`. The new operation applies
this mechanism to the actual full differential coefficient output for x²+y³,
then performs the next existing contact construction without supplying a
manually simplified ideal.

`VerifiedRelativeSnc` checks every nonempty subset of an initially ordered list
of divisor equations. It either proves that its intersection is empty, or
constructs all maximal minors of its Jacobian in the verified relative étale
frame. The intersection equations, those minors and the same guard relations
must generate the unit ideal. This certifies relative rank at every algebraic
point of that intersection. All parameter derivatives remain zero. A failed
check retains the exact obstruction ideal and subset; it does not substitute a
sampled witness or silently discard a parameter-collision locus. Non-reduced
equations and excessive simultaneous intersections are rejected as unresolved.

The minors use Symbolica's exact `Matrix<AtomField>::det` with statistical zero
testing disabled, followed by native polynomial conversion. The Jacobian rows
reuse the verified frame's native derivations, including dependent-variable and
inverse-guard derivatives. The finite circle control needs two minor opens:
neither minor alone is a unit on the circle, while their combined ideal is.

`produce_monomial_center` accepts a supplied common factorization witness
f_j = (product b_i^alpha_i) q_j in that exact localized quotient and verifies
every recombination. It proves that the *ideal* generated by all q_j is unit;
no individual quotient need be a unit. It exhausts inclusion-minimal subsets
with sum(alpha_i) >= d, keeps their empty-intersection receipts, and chooses the
maximum nonempty subset in the persistent divisor incidence-vector order. The
output is an actual relative-smooth center ideal and the expected controlled
exceptional power sum(alpha_i)-d, rather than a proposed invariant number.

The ordering, minimal-subset inequality and exceptional exponent implement
[Bierstone–Milman 2008, §5 Step II.A, pp. 628–629](https://ems.press/content/serial-article-files/41043).
Their termination proof applies to the full blowup procedure; this stage does
not yet implement that procedure. Its ledger is explicitly initial geometry:
IDs supply an initial order, not an independently certified past birth history.

## Executable controls

Seven new native tests exercise:

1. Same-localization normalization with a nonconstant guard, parameter p, marks,
   zero/unit ideals, wrong-candidate refusal and retained late resource state.
2. Automatic normalization of the actual full differential cusp coefficient and
   another native contact step.
3. All SNC intersections and the marked monomial x²y² of mark 3, whose residual
   generators x and 1-x are jointly unit although neither is individually unit.
4. Empty guarded intersections, nonlinear smooth boundary equations and a
   parameter collision which requires the explicit p != 0 guard.
5. Non-reduced and excess-intersection refusals, duplicate IDs and subset limits.
6. Three-divisor ordered minimal-center selection and a codimension-one Cartier
   center (selected only; its identity blowup has not been implemented here).
7. A genuine two-open minor cover, a native circle quotient with a dependent
   coordinate, an inert parameter, and normalization of an actual relation to
   the zero quotient ideal.

The pre-registration native executable passes all seven controls; the 21 existing imported
resolution tests are filtered, not counted again. Strict direct Clippy passes.
The runtime agent independently reviewed the final arithmetic, localization,
SNC and resource boundaries and confirmed the precise BM incidence ordering
against the primary text. This source review accepts the limited stage only.
The initial lint invocation omitted Cargo's macro environment variable and was
retained as `clippy-setup-failure.log`; the corrected invocation supplies it and
required no source correction. There was no mathematical test failure. The root
coordinator separately reviewed quotient equality, parameter roles, the exact
rank-cover condition and the center-selection implementation before registration.
The registration changes only module paths and test names. All 68 focused
threshold Cargo tests pass, including the seven new geometry controls. Strict
feature-enabled library/test Clippy and workspace formatting pass. The separate
portable consumer passes its existing 88 controls; this is a host portable
backend check, not a browser run. Raw gate logs remain in ignored `target/`.

Preflight limits cover subset/minor counts, polynomial degree/term bounds,
marked powers, mixed products and retained ideal slots. Native F4 internal
allocation is not a hard-bounded operation; an external caller process limit
remains necessary. Resource-incomplete outcomes retain original owners and
completed bases/strata/counters. No library worker or execution loop is added.

## Next constructive dependency

The next stage must construct adapted graph-coordinate opens for the selected
SNC center, produce all standard blowup charts, verify relation/guard pullbacks,
and transport each old reduced divisor with exact strict-transform/unit data.
New exceptional birth IDs must be created by this checked transition and kept
separate from a fixed old-boundary snapshot. Cartier centers need their explicit
identity-map case. Only then can the monomial producer be iterated under the
published decreasing invariant. Relative parameter strata, overlap gluing,
real nonempty branches, disjoint integration coverage, the general companion
recursion and auxiliary continuation remain separate unresolved obligations.
