# Repeated local resolution transitions

The native resolution module now transports recursively derived centers through
relative étale blowups and continues an admitted local companion problem to
checked principal/SNC terminals where supported. This is a local algorithmic
milestone, not a complete BM driver or a real integration atlas.

## Mathematical and ownership review

The producer and independent runtime reviewer checked the construction against
the [Bierstone–Milman algorithm](https://ems.press/journals/prims/articles/2154),
especially the original coefficient presentations and induced lower-dimensional
problems. Root reviewed source ownership, continuation states, terminal
certificates and the frozen registration boundary.

One shared graph-coordinate and standard-chart implementation serves both the
existing monomial path and general admitted centers. Every standard pivot,
complement open, original equation and guard is retained. The original relative
Jacobian includes the adaptation determinant; the exceptional monomial alone is
not reported as the full measure.

Strict contact supports use native Lex elimination for saturation by the new
exceptional divisor. The temporary inverse used for that elimination is removed;
it must not delete the exceptional face. Exact support equations, relative frame
minors and their cover are checked before transporting marked presentations.
Parameters remain inert. A support confined to an exceptional parameter value
requires its own stratum rather than treating that parameter as invertible.

The physical parent, original companion/coefficient presentations and lower
auxiliary problem remain distinct owners. The initial empty lower boundary is
attached to the **original** auxiliary problem before the ambient transition.
Its induced chart receives the actual exceptional birth through a checked
center pullback. A new root constructed on the already transformed support does
not preserve this history and is rejected. Original coefficients are carried;
they are not redifferentiated from the transformed parent.

`LocalCompanionContinuation` exposes synchronous caller-stepped work. Accepted
state changes are atomic; bounded retries retain accepted evidence. Completion
checks every initial chart, child chart and factor leaf. Empty marked cosupport,
empty support and a principal divisor with checked SNC are different outcomes.
Distinct locally proposed centers require gluing unless their ideals are
verified equal on the same admitted ambient chart.

## Ecosystem and memory audit

API, source and executable checks confirm reuse of Symbolica polynomial
replacement, differentiation, native F4, quotient/remainder and matrix
determinants. Shared elimination, Cartier-division discovery and center lifting
were extracted from existing owners. No alternative CAS, AD, graph, root solver
or serialization system was added. The adopted GrevLex membership shortcut and
native sparse determinant preflight remain unchanged.

The caller owns execution and resource limits. This local frontier retains its
geometric evidence in memory and supplies node/depth/operation limits; it is not
yet a disk-backed global resolution driver. Native algebra calls still require
caller-owned hard process limits. These tests do not establish aggregate RSS
scaling for full generation or confer an integration-ready HEPKit object.

## Evidence and remaining work

Eight new production test groups pass, including noncoordinate centers in an
implicit ambient variety, strict saturation, parameter-stratum refusal,
original coefficient transport, second/third transitions, history mutations,
bounded retries and reversed work order. The cusp and `(x²,y³)` controls reach
principal/SNC terminals through the reusable caller-stepped path. At this first
milestone, the harder `(y²-x³,y³)` nonprincipal control remained pending.

The isolated resolver suite passes all 94 tests in 12.02 seconds; the new groups
take 10.54 seconds. Strict isolated library/test Clippy and formatting pass.
These are algebraic correctness timings, not physics integration benchmarks.

After registration, the joined native threshold suite passes 181 tests with
one existing ignored test (29.02 seconds). Strict native library/test Clippy
passes (23.98 seconds), as do workspace formatting and whitespace checks.

Further nonmonomial lower recursion, successive companion cycles,
compatible ambient localizations, center gluing, general parameter strata,
global termination and the disjoint closed-face integration atlas remain
required. The current local success does not complete those acceptance gates.

## Successive old-incidence continuation

The next local milestone preserves an `EmbeddedPresentation` through repeated
ambient transitions. It retains the original coefficient `C`, the current
auxiliary problem `J`, the same original old-boundary snapshot, and the issued
lower-dimensional history root. When every retained support open proves `J`
resolved, a checked strict decrease of old incidence creates the new sum
`C + boundary`. This is a new source definition; it neither resets the lower
history nor pretends to be a controlled transform of the old `J`.

Native strict-support saturation, relative minor covers, supported quotient
division, old-boundary sums and center lifting are shared with the initial path.
The complete lower-center pullback must be exceptional times a unit ideal.
Every old divisor and new exceptional birth remains accounted for. Completion
also checks each support task's source, ledger, factor leaves and actual owner.

On a checked descendant of `(y²-x³,y³)`, `C=q³/32` remains nonunit when `J` is
already a unit. This exposes an incorrect replacement of the original
coefficient by the resolved auxiliary problem. The full caller-stepped control
now finishes with 34 retained nodes, physical blow-up stage six and checked
principal/SNC local-divisor certificates at every terminal leaf. Reversed work
order agrees; an injected zero-operation budget leaves accepted state intact.
Missing births, a reset history root, changed coefficient and omitted support
tasks are rejected.

All 96 isolated resolver tests pass in 90.15 seconds; strict isolated Clippy
passes in 11.39 seconds. These remain local algebraic controls. The repeated
dispatcher currently handles monomial descendants, and the exercised embedded
supports have codimension one. Genuinely nonmonomial lower recursion, arbitrary
support towers, general new-companion cycles, global gluing and the real
integration atlas remain open. The frontier is in memory; this is not durable
checkpointing or a measured bound on full-generation residency.

Root and the independent runtime reviewer accepted this narrower milestone
after checking original-data transport, complete support inventory, source
redefinitions, birth/history ownership, atomic work acceptance and native reuse.
After import, the joined threshold suite passes 191 tests with no failures and
one existing ignored test in 114.62 seconds. Strict library/test Clippy passes
in 23.50 seconds; formatting and whitespace checks pass.
