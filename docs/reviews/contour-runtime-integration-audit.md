# Dynamic runtime integration audit

2026-10-10, coordinating-agent review of the uncommitted runtime increment
following `c1f931a`. Public native dynamic analytic admission now passes the
focused gates below. Physical multiloop, CLI, portable and installed HEPKit
acceptance remain separate requirements.

## Numerical ownership and optional checks

The native mapping requirements discover executed callback instructions and
reachable alias bodies once during preparation. Ordinary and fixed evaluators
retain their existing execution variants; they do not enter the dynamic
thread-local failure protocol while sampling. Dynamic unchecked evaluators
retain the essential failure fence and native batched execution. Only checked
evaluators own a certificate specification, observations and ball workspace.

An unchecked matrix with a failed callback discards its provisional matrix and
uses the existing per-point precision rescue. A checked matrix validates each
row separately. This costs more under `always`; it must not be attributed to
unchecked production. The saved original program remains the source for each
numeric domain. A policy remap must neither regenerate expressions nor rerun
Horner/CPE optimization.

Each numeric owner holds independent mutable validation scratch and counters.
The immutable specification shares saved native programs and source metadata.
Preparation scopes restore their previous state on exit and cannot cross
threads. Production diagnostics must be aggregated at the existing caller-owned
work boundaries; no numerical library worker pool is introduced.

## Exact contributions

The exact path keeps the complete native Atom vector until all contributions
have been combined. Symbolica's direct vector API shares its existing function
cache and preserves lazy branches. Checked evaluation inspects only actually
executed dynamic root values. Unchecked evaluation never iterates that cache.
Real candidate centres are exact rationals, including both double-float limbs;
a complex candidate additionally requires an exactly zero imaginary centre.

A failed numerical or certificate attempt retries the entire vector. Values
and certificates from different attempts must not be mixed. The coordinating
review requested that final diagnostics preserve both callback and certificate
failures when different attempts fail differently; the exact-path agent added
that correction and its focused regression passes.

The first combined exact test gate exposed a separate aggregation assumption:
native addition alone leaves `f(p) - (f(p) + 1/p) + 1/p` factored, rather than
returning literal zero. This is expected Symbolica behavior, not a direct-vector
API defect. Public API, source and executable checks identify native
`expand_num` as the narrow remedy. It distributes numerical coefficients and
treats function arguments as opaque; the probe preserves root keys and returns
`[0, 6]` at `p=0` without executing a cancelled callback. The generation and
resident-assembly paths apply this normalization before pruning exact
request associations. Selected-record loading also combines exact Atoms, so it
uses this same normalization. No smooth density, evaluator or certificate is
regenerated or optimized during that combination.

## Source and pilot coverage

One validation source can serve several stochastic sectors and exact terms.
Native `ContourValidationChart` therefore retains the complete sector list and
an exact-contribution flag. Its scope helper owns the selection rule, including
the legacy singular-field fallback. Python exposes these native fields without
reimplementing selection. Sources with no surviving requests are excluded.

The saved checker runtime-parameter ordering is compared with the numerical
owner's native symbols. A restoration test exposed a redundant comparison of
`Symbol::get_name()` with canonical Atom text: equivalent native symbols can
have different textual spellings. Only that redundant string comparison was
removed; the mandatory ordered native-symbol comparison remains. The fixture
retains a physical parameter that appears only in the prefactor.

Pilot receipts are tied to the actual planned owner, point, binding epoch and
unique plan nonce. Checked private numeric owners execute the actual generated
program; successful certification in the accepted precision attempt supplies
coverage. The cache is bounded by resident sectors, is not cloned with a
binding, and is released when preflight finishes. Pilot counters describe
accepted certified coverage, while production counters also retain failed
rescue attempts. This fencing belongs only to caller-driven preflight; it adds
no production sampling identities or RNG draws.

The present positive-residual proof accepts exact rational nonnegative
polynomial coefficients with a positive constant lower bound. It is independent
of kinematic rebinding and covers the ordinary graph U polynomial after
extraction. Parameter-dependent positive residuals lacking this proof are a
reported limitation, not implicitly admitted by a sampled positive value.

## Remaining acceptance evidence

The combined native all-target check on Symbolica/Numerica `1e1cb169` passes.
The current focused exact gate passes ten tests. Recipe tests pass seventeen
and artifact tests forty-five, each with one intentionally ignored child-process
entry exercised by its parent. These include the actual saved-record
numeric-sign cancellation. All eighteen dynamic tests now pass, including the
complete restored binding, actual pilot execution, policy remapping, changed
kinematics and atomic-failure lifecycle on eager and SymJIT owners. These are
not a strict lint or complete physical scientific suite.

The first public analytic run passed its independent native reference identity
but failed both numerical pilots. A native-IR probe isolated four identical
radius calls under direct translation, compared with one under optimized
translation; this is not a stale precision retry or a subtraction-face collision.
The observer's unconditional rejection of a repeated callback was therefore
too restrictive. Its correction coalesces only the identical exact
candidate and precision for an already admitted request, retaining rejection
of conflicting candidates, unknown requests and missing coverage. Each actual
callback still returns its own tracked numeric value, and the retained exact
candidate is certified against every associated source/face. Native common
subexpression reuse is fixed in [Symbolica PR #60](https://github.com/symbolica-dev/symbolica/pull/60),
independently reviewed and tested with six new cache tests and fifteen existing
evaluator tests. No separate FastSecDec optimizer or runtime root memoization
is introduced. These consumer results still use `1e1cb169`, before that cache
improvement, so correctness does not depend on elimination of repeated calls.

A later repeated-pole test exposed a FastSecDec solver-budget mismatch:
256 iterations were insufficient to satisfy a 3,322-bit bracket tolerance.
The structurally quadratic envelope now uses native positive reciprocal square
root, retaining tracked uncertainty and the complex correction. Higher-degree
envelopes use a checked finite budget of `max(256, 4 * precision_bits)` without
relaxing convergence. This budget is not claimed as a universal convergence
bound; exhausted or nonfinite solves remain errors. A zero centre in a retained
higher coefficient does not trigger the quadratic specialization.

The resulting callback gate passes **23 tests**, including tracked real and
imaginary uncertainty, high precision, duplicate/conflicting observations and
fresh-process restoration. Empty and zero-dimensional generation passes
**four tests**, including literal zero, genuine nonzero exact contributions
and continued rejection of an identically singular causal polynomial.

The public analytic suite passes **three tests** in 1.75 seconds: eight endpoint
cases spanning both constructions, symbolic/numerical-dual generation,
Taylor/IBP and poles of orders one and three; a full complex threshold-bubble
vector with artifact reload, all validation policies and the stationary
negative-real branch; and an independent Symbolica reference identity.
The endpoint controls retain their original 8,192 quadrature points and
tolerances. There is no private admission bypass or weakened numerical gate.
Installed HEPKit bindings, portable/WASM execution and physical multiloop
results remain required before phase completion.

The subsequent dependency transition selects public owner revision `516beb37`,
including the independently tested direct-callback cache correction. All three

revisions change. The standalone host-portable suite on that source passes

analytic controls without changing quadrature or tolerances. This establishes

The unchanged public analytic controls also pass **3/3 under actual WASM**
