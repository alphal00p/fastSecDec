# Native threshold preparation and recovery

The first executable native preparation adapter joins existing HEPKit
parametrization, verified symGCAD, rational interval regularization, symbolic
continuation and detached compilation. Its admitted scope is a complete fixed
rational fiber with one compact integration coordinate. Unsupported algebraic
boundaries, higher dimensions and partial selections return explicit errors.
This is an executable milestone, not the general endpoint resolver.

Preparation runs synchronously in the caller's process. The returned receipt
contains immutable file references and semantic identities; it retains no
global decomposition, expression vectors or compiled evaluators. Native status
snapshots report stages, counts, timings and durable evidence. The CLI can run
this operation in a recyclable child without importing its heavy state into
the coordinator.

Cancellation after the raw GCAD record has been written retains a recovery
checkpoint. Recovery reconstructs the native request and repeats independent
verification, then repeats continuation admission without rerunning GCAD.
Completed preparation additionally requires the original canonical mathematical
identity. Previously compiled records may be reused only after that fresh
admission and their original work associations and byte digests are checked.
A serialized observation does not create a verified mathematical object.

The compact publication constructor requires a caller-authenticated preparer
response, bound to the original input, build and child lease. It checks the
closed contribution inventory without repeating symbolic work or pretending
to replay a global proof. Library callers retain responsibility for this
execution boundary and for process memory and time limits. Transport-byte caps
are not decoded-memory limits.

The implementation reuses the native State/Atom codec and existing generation
settings representation. Exact parameter specialization is explicit. Faithfully
represented numerical input retains its separate provenance; ordinary
integration bindings never silently specialize generation. Root and an
independent runtime agent reviewed these ownership and scientific boundaries.
The review caught a malformed binding-count overflow, now checked and covered
by a regression.

Controls exercise cancellation, recovery without a Solve event, stable semantic
identity, fresh preparer processes, malformed transport, explicit unsupported
routes, full-vector save/reload, and a native HEPKit massive bubble against the
existing OneLOop reference. General algebraic resolution, global artifact proof
replay and complete CLI orchestration remain separate gates.
