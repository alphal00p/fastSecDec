# Retained generation metadata and portable version two

`GeneratedIntegral::metadata()` retains the admitted input-domain assessment and every original chart, including charts combined by exact symmetry or absorbed into an exact/zero contribution. `CoordinateMap` stores native source/target symbols, the actual Atom substitution images and the real measure Jacobian. Mapping uses those images and the same native monomial measure factors. The exact Integer `SectorMap` remains geometry provenance; no CAS was introduced into the geometry crate.

These are **pre-subtraction pullbacks**. Numerical sector vectors may also contain analytically integrated boundary pieces, so the records do not assert that evaluating the raw pullback reproduces a subtracted coefficient vector. Projective charts retain the fixed parameter explicitly: their images are gauge coordinates with that parameter one, not normalized simplex coordinates. The positive real measure factor is not an oriented or complex determinant.

Each chart records its original index, symmetry representative, the permutation from this chart's target coordinates to the representative's target coordinates, and an optional numerical kernel index. A missing kernel index means no numerical contribution at the requested orders: exact, cancelled or truncated to zero. Separate exact coefficients per original chart are not retained. Association construction uses one representative-index map and one final chart pass.

`DomainAssessment` records source coordinates/domain, the sole implemented branch policy `NoThresholdReal`, the caller's explicit assertion setting, and factor-level certificates. An explicit interior assertion remains distinct from the independently checked boundary resolution. Positive coefficients and negative coefficients with integer exponent retain their exact certificate categories. Complex scalar weights remain supported; this metadata adds no threshold continuation, contour or GCAD algorithm.

New generated artifacts use version two. Their content identity includes these semantic records. Loading validates symbols and dimensions, factor certificates through the existing native domain checker, exact map invariants through `SectorMap::validate`, image/Jacobian agreement through the same coordinate builder, representative/permutation/kernel references, and kernel coordinate correspondence before compilation. A checksum protects consistency with the serialized artifact; it is not proof that arbitrary supplied coefficient expressions were derived from an independently available original graph.

Version-one artifacts load and re-emit with their original hash/schema. `KernelSet::generation_metadata()` returns `None` for them; no certificate or map is invented. Scientific policy metadata affects version-two identity, while timing observations remain external.

Four focused regressions passed in `output/weighted-metadata-tests.log`: actual regular pullbacks and projective/orthant map meaning; certified/asserted and exact-chart roundtrips; resigned semantic tampering plus unchanged legacy identity; and zero-dimensional cube/orthant exact densities. The final workspace gate additionally covers existing graph, Laurent, complex, runtime and cross-process artifact behavior. Independent source review is owned by the HEPKit agent.
