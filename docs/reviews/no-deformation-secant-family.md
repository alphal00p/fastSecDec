# Checked regular-section endpoint families

`threshold::regularization::secant::NormalizedFamily` connects verified implicit
cell boundaries to the existing symbolic subtraction and Laurent engines.
It is a sufficient endpoint-family issuer, not the general algebraic resolver
or authority to publish an integration artifact.

## Admission and retained evidence

The constructor requires the complete native verified two-cell decomposition of
a fixed unit cube. Every prefix interval is the actual full unit interval; both
cells share the same final-axis root selector. One signed derivative margin
covers the entire final-axis interval, including its closed faces. The polynomial
degree is governed by the existing resource limits, without a quadratic special
case. A separate root bracket alone would not establish this admission.

Native polynomial division constructs exact secants and width identities.
Prefix monomial extraction and a closed positive-unit certificate give the
width normal form. The positive reflected measure is included once. Original
factor polynomials, exponents, scalar normalizations and term/factor indices
remain in the active-factor ledger. Inactive non-polynomial factors with zero
exponent remain in the immutable source request; they need no unit proof.
Singular factors must be exact scalar multiples of the
selected polynomial or separately certified closed units. Polynomial numerators
remain composed native FunctionMap calls, with finite epsilon-polynomial bodies.
Every original causal phase retains its regulator dependence.

Endpoint powers include the width valuations multiplied by the sum of the
section exponents plus one. The issuer checks the whole cell inventory and a
common absolute-convergence strip before continuation, then reuses the existing
meromorphic-prefactor admission to establish a nonpole witness in that strip.
These checks justify continuation of a common analytic family; omitted seams
are not assumed irrelevant to a distributional integral.

`continue_symbolically()` consumes the native generation settings and calls the
shared symbolic endpoint engine. Numerator derivatives use Symbolica's chain
rule and its native finite derivative registration, including all coordinate-map
dependencies. The source-coordinate jet allowance is the dimension times the
per-unit-axis subtraction allowance; this accounts for composition without
introducing numerical endpoint jets. Individual chart expressions and endpoint
profiles remain available alongside their coherent sum. `expand_vector()` uses
the existing complete Laurent-vector construction.

## Scientific controls

The native controls cover:

- A quintic section with separately nonzero cell poles, exact coherent pole
  cancellation, and the independent finite-imaginary density `pi/P_y(x,r(x))`.
- Complete two-term complex Laurent vectors and symbolic Taylor/IBP agreement.
- `x*y^7+y-x`, whose polynomial degree drops on the `x=0` face while the selected
  root remains regular. The full polynomial and face are retained.
- Epsilon-polynomial numerators, an additional positive denominator and an actual
  three-dimensional cube with dimension-generic endpoint storage.
- A repeated pole whose genuine corner pole is retained, plus explicit refusals
  for an absent common strip, cancellation, degree limits and incompatible
  generation routing.

The frozen independent harness passes eight scenario groups in 0.784 seconds;
strict native Clippy passes in 26.367 seconds. The finite-imaginary point-oracle
error is at most `8.88e-16`. Observed outer runtime is 1.946 seconds and sampled
peak RSS is 39,411,712 bytes. These are small f64 correctness controls, not an
integration benchmark or a high-precision accuracy certificate. Root verified
all 37 source/evidence pins before importing the five registration files.

Registration reuses the existing parent `ConvergenceStrip` directly and the
existing generation reexports. It does not install the harness's extracted
private modules. An initial registration build caught private-module paths;
those paths were replaced with the already available crate-private reexports.
No algorithm or acceptance condition changed. The joined native threshold suite
passes 193 tests with no failures and one existing ignored test in 114.01 seconds.
Strict library/all-test Clippy passes in 31.73 seconds; workspace formatting and
diff checks pass.

Independent source reviews by root and the resolver agent checked the exact
width/Jacobian identities, original causal phases, all-face unit hypotheses,
common family, source ownership, complex vectors and resource refusals. Existing
Symbolica, symGCAD, endpoint, Laurent and meromorphic capabilities supply the
algebra; no alternate CAS, root solver, AD, estimator or execution pool is added.

## Remaining scope

The first issuer rejects runtime parameters, noncube/projective sources,
additional GCAD subdivisions, interacting extra normals and nonzero final-source
monomial powers. It does not resolve root collisions, algebraic towers or general
auxiliary-regulator cancellation. The separately tested two-root secant geometry
is not yet admitted by this constructor.

Coordinate-free algebraic coefficients remain owned callback expressions. They
are never sent to the legacy exact materializer or replaced by zero. Root-aware
exact contributions, fresh-process callback restoration, complete precision
rescue and integration-kernel publication remain separate gates.

Preparation is synchronous and caller-owned. One cooperative geometry budget
covers certificate and meromorphic preparation. Input limits and checks between
native operations are not a hard aggregate allocation limit. The full GCAD and
proof owners remain resident; detached records must remove that residency before
bounded-memory integration can be claimed.
