# Native HEPKit threshold session review

This registered binding connects the admitted native rational-fiber preparation and
publication APIs to existing HEPKit input owners. It is not the general algebraic
resolver. Fixed inputs must reach the existing one-dimensional closed-cell and
symbolic continuation certificates. Unsupported paths fail without a contour
fallback or partial archive. Original input graph/family semantics are unchanged.

Reuse was checked against public APIs, native source/tests, and a direct Rust
controller probe. The binding uses PyIntegral::parametrize; native
PreparationOptions/Progress/Receipt and prepare/resume_evidence; immutable native
publication work and the existing indexed archive writer; PyCompilationSettings;
existing GenerationProgress callback/UI cleanup; and RecipeArchive/Kernels.
No graph converter, density algebra, codec, executor, estimator or pool was added.
The direct 3-control protocol probe passes: native cancellation/reverification
without re-solving, dropping the original parametrized density before selected
record compilation, archive/complete complex QMC after owner drop, restart before
raw evidence, and explicit unsupported partial-cell refusal. These are native
protocol controls, not evidence that Python callbacks worked.

A real embedded Python host gate uses public create_symbolica_module,
FeynkitModule::register_module and this leaf's register on the matching native
owner graph. It neither replaces the installed wheel nor launches a server.
Its source tests the HEPKit graph bubble with Gamma/rGamma normalization, scalar
bindings and exact native kinematics; Python callback false, exceptions and
KeyboardInterrupt; native raw-checkpoint reverification; bounded compile calls;
archive ownership/reload/scope; and a separate full-complex QMC action. Its result
passed: one composite host test in 1.51s after an 8m08 matching dependency build
(`embedded.log`). This is an embedded public-module host, not a replacement wheel
or browser/server check. A compile-only native binding check passed beforehand.

Root source review identified three corrected wrapper boundaries: transactional
publication (no Complete snapshot without an accepted Python archive owner), final
compilation time included in the archive snapshot, and parametrization included
in total elapsed. Partial GCAD settings JSON overlays native one-worker defaults;
it must not inherit the owner CLI's multiworker default. The retry counter uses
checked arithmetic. Callback errors after accepted publication preserve the result.

Global CAD/proof owners live within synchronous preparation; their peak is separate
from selective compilation. Transport limits do not bound native decoded RSS.
Cancellation is observed at native boundaries, not inside indivisible CAS calls.
The caller owns any process and hard resource guard. Checkpoints are private to
an immutable session/source/settings owner; no imported JSON establishes proof
or publication authority. Saved archives retain native structural/digest checks;
global proof replay is not implied.

The new classes are native-only. The existing portable archive reader stays
available; no WASM generation acceptance is claimed. The existing Integral.generation_session now accepts the explicit threshold flag,
returning the real threshold session. Its ordinary default retains GenerationSession.
The threshold step method consumes one preparation unit or bounded per-record
compilation units; it never starts sampling. Native-only Python type stubs are
separate from portable refusal. No fake GeneratedIntegral/ChartRecord represents
threshold programs. The common-entrypoint embedded host rerun also passed: one composite test in
1.54s after a 2m10 private frozen-core/link build (`embedded-r2.log`). Native
threshold lineage is retained in catalogue and kernel metadata; the CLI exposes
it through lightweight and selected-record inspection.

This first binding accepts exact fixed native input only. Represented floating
literals are not silently exactified: PreparationOptions.represented remains
None. Exposing that established native option later must also bind its authoritative
GcadRequest::source_identity, including original/exact/policy provenance, instead
of the ordinary exact-input source digest used in this slice. The physical bubble
control supplies exact scalar expressions and rational kinematics.

Independent runtime-agent source review passed both the low-level native owner
and the common-entrypoint dispatch/step delta. Root review corrections were
incorporated before the host test; no scientific tolerance was weakened.

Final gates on the frozen binding source: five native Rust tests passed (three
new owner/protocol controls and two existing complete-vector status controls;
0.55s, `lib-tests.log`); strict native leaf all-target Clippy passed in 24.61s;
format check passed. The portable library check passed in 1m22s. Resolved
portable metadata has only `portable` on FastSecDec/core and the leaf, and no
symGCAD node (`portable-review.json`). This is a host portable-feature check,
not a WASM browser execution claim. The maintained pytest controls are supplied

All substantive implementation and stub ownership remains in the isolated Rust
binding: `threshold.rs`, `threshold/session.rs`, `threshold/work.rs`, and the

separate so the portable API does not reference absent native-only classes.
The production manifest retains repository-relative paths and only enables the

and its six digest dependencies without changing pinned owner revisions.
Private source snapshots and the embedded Python 3.13 link harness remain ignored.
No installed wheel, Community implementation, server, core algorithm or protected
release binary was changed by this slice.

from the compact parent lineage. Missing/nonresident tables fail without loading
more records; the getters confer no global proof authority. Independent HEPKit
source review passes. The existing detached-owner restoration gate now checks

tables for both eager and SymJIT (0.23s); strict native library/test Clippy and
