# Named native coefficients on captured representative 80

This records the next experiment after the small symbolic/program/cold-IR
controls, including the bounded generation failure below. There is no production
strategy change. It targets the original on-shell triple-box Taylor representative
at zero-based index 80, original chart 119, multiplicity four, nine coordinates,
and requested maximum epsilon power zero.

The disconnected source draft is `output/probes/actual_named.rs` with the
`actual_named/{generate,program,reader}.rs` children. The small forwarding draft
`actual_named_endpoint_adapter.rs` exposes the existing endpoint-power rule only
to these test controls. The reviewed draft was temporarily connected, compiled,
archived and byte-restored as recorded below. Kernel program helpers and the
named composition remain their existing owners; no public API or production
artifact identity is changed.

## Bounded native stages

All stages are separate processes with a fresh output directory, 180 seconds
plus five seconds of termination grace, 30 GiB virtual-address space and CPU8.
No stage extends another stage's failed deadline. Serialize all Symbolica
processes. A guarded external C++/numerical reference may overlap only as an
explicitly recorded correctness diagnostic, never a matched timing campaign.

1. **Named generation.** Call the existing test-only named composition with
   Taylor and maximum zero on the exact captured mapped terms. Keep native
   remainder/retry checks and local body/partial/face ownership unchanged.
   Require a nonempty coefficient map and final bound above zero. Export every
   actual order through zero and one shared native alias map as ordinary native
   Atom root/handle/body files, following the existing diagnostic capture
   convention. This is not a new production serializer or alias implementation.
   Record root bytes, unique body and handle bytes, definition counts, request
   counts, native width/coverage attempts, and total phase time. Do not restore
   the full physical coefficient bodies.
2. **Native program.** After generation succeeds, freeze its outputs and rebuild
   native `AliasedAtom` values through `register_alias`. Check map consistency,
   forbidden regulator/formal-function escape, and exact native file identities.
   Call the unchanged production program builder once for the complete vector,
   encode validated native exact IR, and record build/IR sizes and timings.
   Record original Taylor cancellation tuples and use conservative native
   cancellation metadata for the whole vector; no serialized precision facts
   are invented. This stage makes no independent numerical acceptance claim.
3. **Three oracle comparisons.** Only after all source-bound independent oracle
   records exist, use one separate reader process per point. Decode native exact
   IR, compare the complete union of all named/oracle orders at exact rational
   coordinates, and require 512/1024-bit stability plus the existing `1e-70`
   scaled agreement. The finite coefficient must be present. Missing or extra
   orders are checked against zero; they are never silently discarded.
   Separately run native weighted adaptive and forced replay at identical
   rounded binary64 coordinates against their own 1024-bit reference, for
   weights one and `1e40`. Independently verify this rounded-input reference
   at 512/1024 bits before using it. Retain actual precision choices and failures.
   Native IR readers require no coefficient registry or callback state.

The original Taylor cancellation tuples remain evidence of the unchanged
endpoint operation. Since naming can retain branches that the original path
pruned exactly, the numerical guard conservatively adds the coordinatewise
maximum computed from **all original mapped endpoint powers**, through the
existing `endpoint_power` rule and its native rational floor/count operation.
It does not infer that maximum solely from surviving original rows. Checked
integer sums supply the guard degree; the original rows must lie below this
bound. For this fixed capture the resulting tuple is `[0,3,3,3,0,2,0,3,1]`.
This affects precision scheduling only; it cannot alter a coefficient or
establish equality. The full original tuples remain separately in the report.
The adapter remains test-only and must be source-reviewed before execution.

Program serialization and independent-oracle work have separate bounded stages
so failure attribution remains clear. No expensive stage runs automatically
after a preceding failure. Source review and a concrete frozen preflight are
required before the first actual launch. Success would establish only this
representative at three points plus its native composition contract, not a
complete graph, integration, or performance result.

The cfg(test) module wiring and endpoint adapter are temporary probe-only source.
After compiling and copying the probe, archive the exact compiled source and
restore the tracked files byte-for-byte to their pre-build snapshot. Freeze
that archive, not the subsequently restored live tree. The source manifest for
later stages must enumerate every generated root/handle/body and record, native
IR, oracle record and its original native source inputs; a hash map validates
listed files but does not itself prove that the list is complete.

## First actual generation outcome

The temporary source compiled successfully in 12.91 seconds. The immutable build
at `output/diagnostics/native-named-actual-build-1/` records revision `44f5375`
plus the exact test-only compiled source archive and fixed native dependency
identities. The copied test executable SHA-256 is
`f84392659a857be8d2f712a0cb5f9133d1daafa07c00b3252d49ce64575277fe`.
After copying it, the three tracked wiring files were byte-restored against
their pre-build copies and the temporary module files removed. The archived
source, not the restored live tree, defines this diagnostic binary.

After independent source and concrete 89-file preflight checks and the external
generation's explicit exit/reap handoff, only the named generation stage ran at
`output/diagnostics/native-named-actual-generate-1/`. It timed out under the
unchanged 180-second limit. The timer returned 124; the scientific child exited
on SIGINT at the deadline and was reaped after 180.116317807 seconds. Native
peak RSS was 1,831,116 KiB (about 1.75 GiB), with 172.632160 user CPU seconds,
6.301179 system CPU seconds, 2,497,010 minor faults and 3,647 major faults.
All 89 immutable postchecks passed and the process group was gone.

Only `generated/progress.json` exists, at the `native named Taylor composition`
marker. Source/capture/mapped-term identity and cancellation metadata admission
finished before that marker. No completed coefficient map, native remainder
bound, generated root/definition files, program, or numerical oracle comparison
was produced. The separately prepared original-expression oracle binary remains
unexecuted for this experiment. No later stage followed the timeout.

This is an unaccepted actual-target result. Its development/test profile,
guarded external C++ compilation overlap on other CPUs, and different phase
scope exclude a performance comparison with the earlier whole-graph or physical
subtraction runs. The single marker covers regular native series, formal
endpoint assembly, native composition/retries and derivative/face-body lowering;
it does not identify which of those phases exhausted the bound. Coarse test-only
phase telemetry is the next attribution step, before another algorithm change.
